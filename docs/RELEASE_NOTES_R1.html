What Shipped
R1 Delivered Components
Active in production. Every component wired, tested, and versioned.
Active · R1
raglab-common v0.1.0
Shared Pydantic v2 models (Chunk, Document, Embedding, Query, Response, Health), async SQLAlchemy engine, structlog logging, pydantic-settings with RAGLAB_ prefix, RabbitMQ message schemas.
Active · R1
raglab-chunkers v0.2.0
BaseChunker + ChunkerFactory + TextChunker. Fixed-token chunking with sentence boundary backtracking. Shared _boundary.split_into_windows() reused by all R2+ chunkers. 73 tests.
Active · R1
raglab-retrievers v0.2.0
BaseRetriever + RetrieverFactory + DenseRetriever. Cosine similarity via Qdrant. _build_filter() converts metadata_filter to Qdrant must-conditions. 50 tests.
Active · R1
ingestion-service
POST /ingest with idempotency key (SHA256 or caller-supplied). RabbitMQPublisher with publisher confirms. Duplicate detection via Postgres. Dead letter queue topology declared at startup.
Active · R1
embedding-service
AzureOpenAIEmbedder (batch API with index-sort), OpenAIEmbedder, OllamaEmbedder, VertexEmbedder stub. POST /embed + /embed/batch. All providers loaded at startup, missing creds skipped.
Active · R1
indexing-service
QdrantIndexer with idempotent ensure_collection. Full ChunkModel payload stored in Qdrant. DocumentRecord + ChunkRecord ORM models in Postgres. POST /index → ensure → upsert → write.
Active · R1
retrieval-service
POST /retrieve: embed query via embedding-service HTTP → DenseRetriever → ranked ChunkModel list. Cached embedder pattern (embed once, reuse). Stub retrievers return 400 with release info.
Active · R1
llm-service
AzureOpenAIProvider, OpenAIProvider, AnthropicProvider, OllamaProvider, VertexProvider stub. BaseLLMProvider: context numbering, 12k char truncation, timing. POST /generate → ResponseModel.
Active · R1
pipeline-service
RabbitMQConsumer with prefetch=1. Full pipeline runner: local read → TextChunker → embed HTTP → index HTTP. Retry with incremented retry_count up to MAX_RETRIES=3, then DLQMessage.
Active · R1
api-gateway
HealthRegistry: async TTL-cached polling of all 12 services. Health-aware routing: 503 before proxy if service unavailable. Strips hop-by-hop headers. 13 proxy routes under /api/v1.
Active · R1
ui-service (Control Panel)
Dark industrial Jinja2 + vanilla JS. 5 routed pages. All knobs for all 7 releases — R2+ greyed with "Coming Soon" pills. Config Library with localStorage. Health dashboard. Query + Ingest pages.
Stub · R4/R6/R7
graph / observability / auth
Scaffolded and health-check ready. Return activates_in field on root. Docker Compose health checks pass. UI nav items visible, disabled.

Get Started
Running R1 Locally
# 1. Clone and configure git clone https://github.com/tamalkundu007/raglab.git && cd raglab cp .env.example .env # Edit .env: set RAGLAB_AZURE_OPENAI_API_KEY, RAGLAB_AZURE_OPENAI_ENDPOINT, # RAGLAB_AZURE_OPENAI_CHAT_DEPLOYMENT, RAGLAB_AZURE_OPENAI_EMBEDDING_DEPLOYMENT # 2. Start infrastructure docker-compose up -d qdrant postgres rabbitmq # 3. Start all services docker-compose up # 4. Open Control Panel open http://localhost:8009 # 5. API Gateway (all routes) open http://localhost:8000/docs # Run tests (zero infra needed) uv run pytest packages/ services/ tests/ -q
