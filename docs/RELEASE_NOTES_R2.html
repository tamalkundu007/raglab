Design Notes
Key Decisions
Reuse rule: zero duplication
Every R2 chunker calls _boundary.split_into_windows() for token+boundary splitting. PDFChunker uses it within pages. DOCXChunker uses it within heading sections. MarkdownChunker within header sections. HTMLChunker for oversized nodes. ExcelChunker for oversized row groups. HybridChunker for Pass 2. One algorithm, six callers.
Column context in ExcelChunker
The row strategy produces Name: Alice | Age: 30 | City: London rather than Alice,30,London. A retrieved chunk is self-contained — the LLM never sees raw CSV values without knowing what they mean.
Heading context in DOCX/Markdown
include_heading_in_chunk=True prepends the section heading to every chunk produced from that section. A chunk retrieved from the middle of a long section retains its section context for downstream generation.
HybridChunker ≠ HybridRetriever
Tested and documented explicitly. HybridChunker = structural splitting + token windowing. HybridRetriever (R3) = dense + sparse retrieval fusion. Completely different concepts. RetrieverFactory.create("hybrid") raises NotImplementedFeatureError — verified in test.
Credential discipline
All cloud credentials come from env vars via pydantic-settings with RAGLAB_ prefix. No credential is ever accepted as a plain function argument. boto3 and azure-storage-blob are at module level — tests patch the class, never the credentials.
HybridChunker lazy init
Source chunker instantiated via ChunkerFactory.create() on first chunk() call, not in __init__(). Prevents circular import: factory.py imports HybridChunker; if HybridChunker.__init__ imported factory, Python would deadlock at module load.
Quick Start
Using R2 Chunkers
# PDF with page boundaries chunker = ChunkerFactory.create("pdf", config={ "tokenizer": "word_count", "chunk_size": 500, "respect_page_boundary": True, "page_metadata": True, }) chunks = chunker.chunk_pdf_bytes(pdf_bytes, doc_id="report-001") # Markdown with H1/H2 splits chunker = ChunkerFactory.create("markdown", config={ "header_levels": [1, 2], "include_header_in_chunk": True, }) # Hybrid: markdown structure + token windowing within sections chunker = ChunkerFactory.create("hybrid", config={ "source_chunker": "markdown", "max_unit_tokens": 1000, "chunk_size": 300, "source_config": {"header_levels": [1, 2]}, }) # Excel with row strategy — column context preserved chunker = ChunkerFactory.create("excel", config={ "sheet_strategy": "row", "row_grouping": 5, }) chunks = chunker.chunk_excel_bytes(xlsx_bytes, doc_id="sheet-001")
