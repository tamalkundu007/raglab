QuestionAnswer
Why Postgres + NetworkX, not Neo4j?No new infra. Postgres already running for metadata. NetworkX rebuilds the graph in-memory with TTL cache. Revisit if traversal depth > 3 proves slow in production.
Why Leiden, not Louvain?Leiden guarantees well-connected communities (Louvain can produce disconnected ones). RBConfigurationVertexPartition with tunable resolution parameter.
What's the "blast radius" framing?Vector search finds chunks similar to the query. Graph traversal finds chunks connected to the answer even when they don't resemble the query text — surfacing links nobody wrote down together.
Entity dedup strategy?name_normalised = name.lower().strip(). Dedup by (name_normalised, entity_type, collection). "Apple" and "apple" are the same entity. chunk_ids appended pipe-separated on re-extraction.
The Insight
Why Table Stitching Matters
This is an embedding problem masquerading as a parsing problem.
Without stitchingWith stitching
Page 2 chunk (orphaned):
"Carol | 91 | Marketing
Dave | 85 | Marketing"

→ No headers. LLM doesn't know what 91 means.
→ Query "who scored highest in Marketing?" fails.		 Stitched chunk (pages 1–2):
"| Name | Score | Department |
| Carol | 91 | Marketing |
| Dave | 85 | Marketing |"

→ Headers travel with data.
→ Query answers correctly.
Interview Angles
What R4 Unlocks
"What does Graph RAG solve that vector RAG can't?"
Multi-hop questions and connections spread across documents. Vector retrieval finds chunks similar to the query. Graph traversal finds chunks connected to the answer — surfacing links nobody wrote down together. The blast radius framing.
"How do you build a knowledge graph from documents?"
LLM entity/relationship extraction → GraphEntity + GraphRelationship in Postgres → NetworkX DiGraph → Leiden community detection. Dedup by name_normalised. Defensive parser — malformed LLM JSON never crashes the pipeline.
"OCR + multimodal for image PDFs?"
Rasterise via PyMuPDF → pytesseract OCR → split_into_windows. Images extracted as base64, sent to llm-service vision endpoint for captioning. CaptionService is decoupled. OCR failure on a page is a warning, not a crash.
"Table stitching?"
Tables spanning page breaks produce orphaned rows with no column context. Detect continuations via header repeat + column count alignment. Reconstruct the logical table before chunking. Headers always travel with data rows.
"Graph RAG as additive?"
GraphRetriever has three modes: classical (pure dense), graph (traversal only), hybrid (dense + expansion). Caller chooses per query. No query is silently rerouted. Same discipline as the R3 retrieval layer.
"Terraform without static credentials?"
Azure: use_oidc=true + federated credential in Azure AD. AWS: OIDC identity provider from EKS cluster issuer + IAM role assumption. No client_secret, no AWS_ACCESS_KEY_ID in any file. Secrets in Key Vault / Secrets Manager — set by operators post-apply.
