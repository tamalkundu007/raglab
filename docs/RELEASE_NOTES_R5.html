Log + Trace
CHUNK QUALITY GATE
Ingestion-time. Four heuristic subscores: size, boundary integrity, information density (boilerplate + repetition), encoding health. Optional LLM judge in inconclusive band. Quarantine: exclude / flag / re-chunk.
RETRIEVAL FEEDBACK LOOP
Query-time. Detects weak results (too few, top_score < floor). Escalates through configurable strategy order (Dense → Hybrid → BM25). Bounded retries. Best result tracked across all attempts.
ANSWER GROUNDEDNESS CHECK
Post-generation. Sentence-level word overlap against context. LLM judge in inconclusive band. On fail: re-prompt with stricter grounding, re-retrieve more context, or flag low confidence.

Interview Angles
What R5 Unlocks
"How do you stop confident hallucinations?"
Groundedness gate post-generation. Per-sentence word overlap against retrieved context. On fail: re-prompt, re-retrieve, or flag — never emit a confident wrong answer. Failing loudly beats failing silently.
"How do you detect bad chunks?"
Four heuristic subscores at ingestion: size, boundary integrity, information density (boilerplate + bigram repetition), encoding health (U+FFFD, alpha ratio). LLM judge only for the ambiguous middle band.
"Self-healing without a black box?"
Every gate is an explicit detect→score→remediate decision with a typed result object, a logged reason, and a config toggle. The Healing Trace page shows the full audit trail per query. Not magic.
"Embedding cost control?"
SHA-256 keyed Redis cache, scoped by provider + model + text. hit_rate_pct on /embed/cache/stats is the ROI metric. Re-ingest a corpus where 80% of chunks are unchanged: 80% fewer API calls.
"LLM-as-judge tradeoffs?"
Cheap dedicated model (gpt-4o-mini), separate from generation model. HEURISTIC_FIRST avoids LLM calls for clear pass/fail. Known limits: ~0.7–0.85 correlation with human judges; heuristics are faster and cheaper for obvious cases.
"Retrieval strategy selection?"
RetrievalHealer escalates through a configurable order (Dense → Hybrid → BM25) when initial results are weak. Best result tracked across all attempts. Retriever errors on one strategy don't crash — continue to next.
