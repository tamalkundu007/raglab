Observability Views
Six Native Views. No External Tools.
All served from observability-service. Dark-gold theme. Read-only — never mutates pipeline state.
GET /obs/viewer
Distributed Trace Viewer. D3.js waterfall timeline. Every service hop timed. Depth-indented parent→child spans. Error spans red. Expandable detail panel.
GET /obs/inspector
Chunk Inspector. Exact text of each chunk, token count, quality score, quality action (accepted/flagged/excluded). Filter + sort by quality.
GET /obs/retrieval/scorer
Retrieval Scorer. Per-query strategy, top score, healed badge. D3 score distribution (5 buckets). Healing stats: heal rate %, avg top score.
GET /obs/cost/dashboard
Cost Dashboard. Token totals, estimated cost, D3 7-day trend, per-provider breakdown. Cache hit rate with ROI message.
GET /obs/health/dashboard
Pipeline Health. Job success rate, failed jobs table, self-healing gate firings with pass-rate bars. Auto-refresh 15s.
GET /obs/traces
Trace API. list, get spans, get D3-ready timeline, service stats. All filtered, paginated, error-safe (DB down → 503, not 500).

Interview Angles
What R6 Unlocks
"How do you debug a wrong answer?"
Trace Viewer: every hop timed. Chunk Inspector: exact text + quality scores. Retrieval Scorer: strategy, candidates, healing delta. Pipeline Health: which gate fired. "The answer was bad" becomes a diagnosable chain.
"Observability vs monitoring?"
Monitoring tells you something broke. Observability lets you ask why without shipping new code. OTel traces + structured events + the ability to inspect any past request.
"Why OpenTelemetry?"
Vendor-neutral. Instrument once, swap backends (Jaeger → Grafana Tempo → cloud-native). Same cloud-agnostic principle as the storage/vector/LLM abstractions throughout the platform.
"Cost observability?"
Per-request token attribution + embedding cache hit rate on /obs/cost/dashboard. "73% cache hit rate saves 73% of embedding API calls on re-ingestion" — traceable to a specific endpoint, not a spreadsheet estimate.
"Unit vs integration vs E2E?"
Unit: logic in isolation. Integration: service contracts and async/idempotency/DLQ. E2E: complete user journeys including self-healing paths. Each layer catches a different bug class.
"Zero infra for 1,811 tests?"
PostgresSpanExporter buffers on failure. EmbeddingCache degrades gracefully. Pipeline runner accepts injected mocks. TextChunker uses word_count tokenizer (no tiktoken network). Every test is CI-safe.
