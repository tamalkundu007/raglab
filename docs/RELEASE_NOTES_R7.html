Interview Angles
What R7 Unlocks
"How do you guarantee tenant isolation?"
Enforce at data layer, not UI. Single dependency (ScopedQdrantClient, scoped_cache_key, scoped_storage_path) that all services import. One missed filter per service → zero missed filters when enforcement is in the library. Test adversarially: 39 attacks, all fail closed.
"Collection-per-tenant vs shared collection?"
At 800+ tenants: 800+ collections to manage. Shared collection + mandatory payload filter enforced centrally scales cleanly. Risk of missed filter mitigated by centralizing in ScopedQdrantClient — services can't forget what they never write.
"Why validate JWT at the gateway?"
Single enforcement point. Downstream services trust gateway-injected headers — less duplication, fewer ways to get it wrong. Same principle as tracing (R6) and tenant scoping (R7): centralize the cross-cutting concern.
"OIDC across three providers?"
One abstraction (OIDCProviderBase), three implementations. Provider-specific config, common token handling. Cloud-agnostic identity mirrors the storage/vector/LLM abstractions throughout the platform.
"Nullable tenant fields from R1?"
Forward-compatible schema design. tenant_id as nullable stub from day one meant R7 activated isolation without a migration nightmare. Backward compat: 'default' tenant for existing data. Senior move: design for future constraints upfront.
"How do you test security properties?"
Adversarially. Write tests that attempt the attack, not tests that verify the defense exists. 39 tests, each explicitly attempting a cross-tenant operation. Pass = attack fails closed. The test failing means security is broken.
